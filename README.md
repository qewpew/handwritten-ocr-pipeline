# Handwritten OCR pipeline (image → text)

Полный OCR-пайплайн для распознавания рукописного текста со сканов — **без готовых OCR-движков**. Учебный кейс по компьютерному зрению (сегментация и классификация, image → text).

## Подход
1. **Предобработка и шумоподавление:** направленная морфология ядрами 1×2 / 2×1 (сохраняет тонкие штрихи при удалении salt-pepper шума), удаление мелких компонент через `connectedComponentsWithStats`.
2. **Сегментация:** разбиение на строки по горизонтальным проекциям (суммы строк, деление по серединам промежутков) + сеточное посимвольное выделение в токены 28×28 с центрированием и обработкой пробелов.
3. **Распознавание:** собственная **CNN** (Conv–BatchNorm–ReLU + MaxPool + Dropout → полносвязные слои), обучение на датасете **EMNIST (letters)**; AdamW + CrossEntropyLoss, grid-подбор гиперпараметров, сохранение лучшего чекпоинта.
4. **Оценка:** собственные метрики **CER** (расстояние Левенштейна) и **WER**; end-to-end инференс по всем изображениям.

## Результат
Рабочий end-to-end пайплайн (предобработка → сегментация → CNN → текст). Сильная сторона — сегментация; выполнен анализ ограничений распознавания (домен-гэп EMNIST ↔ рукописный почерк, искажение глифов предобработкой) и намечены улучшения (шумовая аугментация при обучении, работа с исходными изображениями, пост-коррекция текста).
