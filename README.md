# Кейс по распознаванию рукописного текста

Полный OCR-пайплайн для распознавания рукописного текста со сканов (без готовых OCR-движков). Учебный кейс по компьютерному зрению (сегментация и классификация, image to text).

## Подход
1. **Предобработка.** Тут пайплайн раздваивается. Чтобы найти строки, прогоняю направленную морфологию (открытие ядрами 1×2 и 2×1): она склеивает разорванные штрихи и делает проекции строк чище. А сами буквы для классификатора беру из исходного изображения, без морфологии, чтобы не искажать форму - только убираю точечный salt-pepper шум и мелкие компоненты через `connectedComponentsWithStats`.
2. **Сегментация строк.** Считаю сумму чернил по каждому ряду пикселей, нахожу полосы с текстом и делю картинку по серединам промежутков между ними. Полосы ниже порога высоты отбрасываю, чтобы не ловить мусор.
3. **Выделение символов.** Символы на сканах лежат по ровной сетке 28px (по сути это буквы EMNIST в решётке), поэтому режу каждую строку на ячейки фиксированным шагом 28px. Пустые ячейки считаю пробелами.
4. **Нормализация глифа.** Каждый символ привожу к виду EMNIST: вырезаю плотный bbox, масштабирую длинную сторону до 24px с сохранением пропорций и ставлю по центру масс на поле 28×28. Беру глиф в grayscale вместо бинаризации, так сохраняются мягкие края букв.
5. **Распознавание.** Своя CNN: два блока Conv - BatchNorm - ReLU, между ними MaxPool и Dropout, дальше полносвязные слои. Обучал на EMNIST (letters), в обучение добавил аугментацию (эрозия, дилатация, небольшой поворот). Оптимизатор AdamW с CrossEntropyLoss, гиперпараметры подбирал grid-перебором, использовал шедулер CosineAnnealingLR и лучший чекпоинт сохранял.
6. **Пост-коррекция.** Распознанный текст прогоняю через словарь: слова с опечатками правлю на ближайшее по расстоянию Левенштейна, но только если длина слова не меняется - иначе оставляю как есть, чтобы не портить сильно искажённые слова.
7. **Оценка.** Считаю свои метрики CER (расстояние Левенштейна по символам) и WER (по словам). Сравниваю по буквам, приведя оба текста к нижнему регистру без пунктуации - так честнее видно качество распознавания.

## Результат

В итоге на эталонном тексте получилось CER ≈ 0.36 и WER ≈ 0.40, а CNN на валидации EMNIST даёт аккураси примерно 0,96. Это значит, что примерно каждый третий символ распознан с ошибкой, то есть около двух третей букв верные, и текст читается. WER получился выше, и это ожидаемо: одной неверной буквы хватает, чтобы всё слово считалось ошибкой. Буквы на инференсе не совсем то, на чём училась сеть, поэтому распознавание проседает.
